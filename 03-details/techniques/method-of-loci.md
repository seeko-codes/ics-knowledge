## About

The modified method of loci builds upon the original method of loci (more commonly known as the
Memory Palace) to help memorise large strings of arbitrary information.

## Instructions (practice instructions)

1. Create a story or "scene" with different elements for each piece of information.
2. Make elements absurd — mundane and boring elements are not memorable.
3. Keep elements spatially distinct — avoid too many things happening in the same "location."
4. Make elements interdependent — create relationships between elements to help retention.
5. Draw the "scene" into the mind map canvas to serve as a memory anchor. This replaces the normal
   "visualisation" memory cues otherwise used.

The drawing does not need to look good — it only needs to consolidate the information in the
brain. Even a learner with zero artistic ability can use this technique successfully.

## Usage notes / scope

- As a lower-order memorisation method, it is not effective or efficient for information that has
  causal, functional, or conceptual relationships with other pieces of information — arbitrary,
  list-form information only.
- Excels with lists of information, ordered or unordered.
- Works for small lists of just a few items, or longer lists of 30+.
- Should not replace higher-order encoding approaches where a higher-order relational network is
  viable.

## GRINDE-map integration (layers 3–4)

The technique is introduced alongside flashcards as filling the "outer layer" of information — the
arbitrary layer left over once conceptual understanding of the three inner layers is maximised (see
02-concepts/rote-and-mnemonics.md). Per the Camp I competence checkpoint, correct use of the
technique means it integrates seamlessly into GRINDE maps specifically at **layers 3 and 4** — the
scenes it produces are drawn directly into the mind map canvas as memory anchors for arbitrary
detail, in the same way flashcards are restricted to layers 3–4 rather than used for conceptual
information.
