## Overview

Double generation is a practice-test strategy for exposing knowledge gaps that ordinary past-paper practice
overlooks, typically because answers are checked too early or questions are not fully answered before
checking. It is the named remedy for "general knowledge gaps that are not identified during retrieval" in the
silly-mistakes root-cause table (../03-details/tables/silly-mistakes-diagnosis.md) — the case where mistakes
recur across multiple orders of learning and similar errors repeat across practice tests.

## Procedure

1. Do a practice test.
2. Answer each question, writing it out as would be done in a real exam.
3. Mark areas of low confidence.
4. Create a personal answer sheet with "perfect" model answers, using notes and other resources.
5. Compare the original answers against this self-made answer sheet.
6. Compare the self-made answer sheet against the official answer sheet, if one is available.

### What to review and re-encode afterward

Three categories of item emerge as candidate knowledge gaps, each reviewed and re-encoded with an encoding
technique of choice:

1. Questions not confident about.
2. Questions marked wrong against the self-made answer sheet.
3. Model answers found lacking when compared against an official answer sheet.

**Key principle stated in the source:** lack of confidence indicates a knowledge gap even when the answer was
correct — a correct answer may have been due to luck, and being tested on the same knowledge with a variation
of the question may produce an incorrect answer next time.

## Proxy learning side effect

Constructing a personal model answer sheet is claimed to produce learning benefit beyond the tested question
itself, because crafting a "perfect" answer requires learning material *around* the question that was not
directly tested — named as a "proxy learning" effect. Anecdotally, creating the answer sheet is described as
providing learning benefit equivalent to completing five or six additional practice tests without that step,
because it forces both lower-order and higher-order thinking to evaluate what counts as a correct answer.

## Constraints and fallbacks

- **Mental answering is insufficient.** Answering only in one's head does not expose illusions of explanatory
  depth; writing the answer out is required. This is named as a common reason learners use practice tests yet
  still miss knowledge gaps.
- **Skipping the self-made answer sheet** (using only an official answer sheet) is acceptable "in the
  worst-case scenario," but not recommended — the step is described as one of the most useful parts of the
  strategy precisely because it is generative.
- **No practice test available**: create one, find similar questions online or in a textbook, use AI to
  generate one, or form a small study group and create practice tests for each other — forming a practice
  group is named as the best option where feasible, since it adds the benefit of being challenged from
  another person's perspective.
- **No official answer sheet available**: acceptable to skip that comparison step if there is no time; where
  possible, compare model answers with a study partner's model answer sheet instead, to reduce the chance of
  a missed gap.
