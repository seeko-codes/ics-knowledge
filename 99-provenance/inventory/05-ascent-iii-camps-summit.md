**Highlights**
- 2-4 Rule — chunk sizing rule: aim 2 branches/node, never >4; ≥4 → new chunk; <2 → merge/re-chunk. Core chunking mechanism.
- GRINDE — Skin-step mnemonic: Grouped, Reflective, Interconnected, Non-verbal, Directional, Emphasised. Final mind-map refinement checklist, extension of VPReFRE.
- Single-node chain / terminal node — diagnostic pattern: 1 in + 1 out (or 0 out) connection = weak/forgettable point; remedy = concatenate/merge/remove.
- Reverse chunking — rechunk around a repeated layer-2/3 element instead of treating it as detail; produces more intuitive structure.
- Mind-map fault taxonomy (quiz-derived) — wheel and spokes, waterfalling, spiderwebbing, cracked glass, islands, unshaped, detail stripped, insufficient chunking — each with cause + fix.
- Intuitive chunking — chunk structures should leverage prior knowledge/feel logical, not just be "correct"; check via reverse-chunking exploration.
- Rule of 3 (flashcard management): Combine (3x correct + related card → higher-order merge), Cut (3x correct, no related card → remove/reword), Critique (3 incorrect of 5 attempts → deep relearn, 5-10 min).
- Leitner system flashcard timing — correct moves forward (1hr→4hr→16hr boxes), incorrect moves back one box.
- Modified method of loci — 5-step procedure (story/scene, absurd elements, spatially distinct, interdependent, draw as memory anchor); for arbitrary/list info only, not causal/relational info.
- WPW (Whole-Part-Whole) — two-stage reteaching technique: Stage 1 layman's terms (4 parts), Stage 2 technical (labelling + elaboration); HVRP method; give ≥3 days after GRINDE map.
- Reconstruction vs recall — reconstruction (Evaluate/Create level, build new valid relationships) vs pure recall; ratio guidance 10-90% to 50-50% depending on student; more reconstruction early, more recall late.
- Multipass system — cramming strategy layering Swiss-cheese-model passes over BHS; inquiry-led vs objectives-led variants with distinct use cases; always logic/concepts before details (opposite of naive cramming).
- ReCOVer essay system — Recall (≤10min), Chunk (≤5min, 3-4 main chunks), Order (≤5min, linearize), Verbalise (remaining time) — exam essay-writing procedure with per-step time budgets and essay-length-by-chunk-count table.
- Breaching questions — procedure for finding known/unknown knowledge gaps late in mastery via LO-keyword cross-mapping.
- MR FIG — exam-attention-to-detail optimization: Mirror calibration, Ritual, Focus training, Image training, Graduated exposure.
- Attention management — flow-state-first alternative to time-boxing; measures success by task completion + flow duration, not clock time; explicit tradeoffs vs conventional time-boxing.

## ics-course/03-growth/07-camp-i/02-flashcards.md
- **stage**: Camp I, lesson 2/5 — flashcards (2 pages: overview + active management)
- **role**: lesson + procedure/rules page
- **terms**: flashcard (prompt/answer card; prompt types: question, fill-in-blank, image occlusion); summary cards (contrasted term — provide summary, NOT generative, distinct from flashcards); microlearning (short study bursts, e.g. 3-10 min, enabled by flashcards); generation effect (producing an answer yourself creates more learning than reading/checking one); hypercorrection effect (higher confidence in a wrong answer + correction = greater learning gain than being right first time); Leitner system (spaced-repetition box system — see procedures); Rule of 3 (Combine/Cut/Critique — see procedures); recognition trap (over-relying on a highly specific cue to recall, rather than true recall)
- **claims**: too many flashcards → overwhelm + high recurring time cost; testing >1 fact/prompt makes correct/incorrect grading ambiguous; flashcards enable spaced retrieval for lower-order info + serve as reference/"second brain" + enable microlearning; long study sessions don't activate microlearning conditions → less effective; digital (app-based, e.g. Anki) is strictly better than physical due to spaced-repetition algorithm automation — benefit of handwriting is "insignificant"; generation effect + hypercorrection effect are key mechanisms (guessing before checking answer activates both)
- **procedures**: General flashcard guidelines (5 steps): (1) use digital (Anki-type) app; (2) only layers 3-4; (3) minimize total count; (4) targeted single-fact prompts, max 2-3 facts/card; (5) always attempt a guess before checking answer. — Leitner system box-movement example (10-step trace: correct→box2(1hr)→correct→box3(4hr)→correct→box4(16hr)→incorrect→box3(4hr)→incorrect→box2(1hr); general rule: correct=forward, incorrect=backward one box). — Rule of 3 (3-part method): Combine (3x correct in a row + related card also 3x correct → merge into higher-order question, must retain lower-order info as prerequisite within new question); Cut (3x correct, no related card to combine with → remove card; flexible — can leave for algorithm to naturally space out; at minimum reword to avoid recognition trap); Critique (3 incorrect out of 5 attempts → return to material, deepen understanding beyond curriculum scope, invest 5-10 min consolidating).
- **criteria**: max ~50 flashcards per topic ("shouldn't need more than"; more = signal of conceptual-learning mistake); max 2-3 facts per card; microlearning session length 3-10 minutes; Rule of 3 thresholds — Combine/Cut trigger = 3 correct in a row; Critique trigger = 3 incorrect out of 5 attempts; Critique remediation time = 5-10 minutes; Leitner box delays = 1hr / 4hr / 16hr (progressive box 2/3/4)
- **failure-modes**: too many flashcards (overwhelm, unsustainable — some students have "hundreds or thousands"); multi-fact prompts (ambiguous correctness); physical flashcards (harder to access for microlearning, no spaced-repetition automation); Leitner system weakness — cards accumulate/overflow lower boxes if many are wrong (200+ cards can become unmanageable) — remedied by Rule of 3; recognition trap (over-specific cue reliance) — remedied by rewording at Cut step; consistently-wrong cards consuming disproportionate time — remedied by Critique (deep relearning) rather than continued low-order repetition

- **figures**: 1920px-Leitner_system_alternative.svg_.png — Leitner system box diagram (external Wikipedia source cited), depicts correct→forward/incorrect→backward box movement.
- **relations**: flashcards use layers 3-4 only (cross-ref to 4-layer learning model established earlier in course, referenced again in Camp II and later); Rule of 3 "Combine" produces higher-order questions — links to Bloom's-taxonomy-style ordering used elsewhere (WPW, interleaving table)

- **terms**: modified method of loci (Mmol) — builds on classic method of loci/Memory Palace; for memorizing large strings of arbitrary information via spatial "scene" story
- **claims**: absurd/interdependent/spatially-distinct elements are more memorable than mundane ones (standard memory-palace principles); drawing the scene in the mindmap replaces standard "visualisation" memory cues; artistic skill is not required for effectiveness

## ics-course/03-growth/08-camp-ii/01-revision-strategy.md
- **stage**: Camp II, lesson 1/5 — revision strategy (4 pages: overview, preparing, pitfalls, effective revision)
- **role**: lesson set (stage intro + conceptual/procedural pages) — explicitly framed as partly recap
- **terms**: knowledge gap (any missing important/relevant information or relationship, identified via self-testing); declarative knowledge gap (struggle identifying correct approach/strategy — common in engineering/coding/physics/maths when conceptual network under-attended); retrieval gap (struggle recalling info — remedy = deeper relational encoding or lower-order memorization depending on info type/layer; high-volume forgetting → usually suboptimal chunk structure, check for waterfalling/spiderwebbing/non-intuitive chunks/"simple question and answer" pattern); procedural knowledge gap (struggle with consistent problem-solving due to errors — from lack of practice/execution interleaving, sometimes conceptual misunderstanding); higher-order knowledge gap (struggle applying knowledge in new/nuanced contexts — missing relationships); expanding-gap spaced repetition (revision-session gaps should lengthen over time; ≥1-2 sessions in first 10 days then continuously expand)
- **claims**: many students revise passively (past papers, re-reading) without appropriate challenge/order variety (per "interleaving table," referenced not defined here); interleaving (practicing under varied conditions) produces better learning than fixed-condition practice; premature answer-sheet checking creates "illusions of knowledge" (explicit common mistake); difficulty (not correctness) is the true signal of a gap — getting a question right may just be luck
- **procedures**: Pre-revision sweep — quickly sweep course material for missed content before revising; use Mmol to replace info-lists with drawings in mind map. — Effective revision 3-part approach: expanding-gap spaced repetition (timing rule below); interleaving (vary practice conditions); gap-seeking (reapply Aim step to study material/GRINDE map, target unknown areas with deliberate questions).
