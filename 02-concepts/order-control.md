## Mechanism

The order in which information is processed is a free variable, decoupled from the order in
which it is presented. One of the key differences between inquiry-based learning and
conventional learning is the order in which information is gathered:

| | Conventional learning | Inquiry-based learning |
|---|---|---|
| What is learned first | The first thing given is the first thing learned | The point of most curiosity or relevance |
| What determines order | How the material is structured/presented in resources, classes, lectures | The learner's own thought process and how their personal knowledge network is being built |
| How detail is handled | Detailed information that feels irrelevant or overloading is learned as soon as it is presented | Detail that would normally overload is delayed until the learner is better able to make sense of it |
| Resulting feeling | Overwhelming or irrelevant at times | Always manageable and relevant, because a path of relevance is chosen |

Because the relationships a learner can build depend heavily on prior knowledge and how new
information can be made sense of, the "best" order to learn a topic differs for each person.
Techniques such as the Traffic Light System are designed to make this ordering deliberate rather
than default.

### Resources are not authored for the learner's brain

Experts present their own knowledge network in a form they assume will make sense to others, but
expertise itself has no inherent "order" — it is non-linear. It is always the learner's job to
take presented information and construct their *own* knowledge network. A common failure pattern
is that learners commit the linear order of teaching to memory instead of reconstructing the
non-linear structure that actually constitutes expertise (figure:
../research/_assets/inline-images/Learners fail to reconstruct proper expertise.jpeg).
Defaulting to the source's grouping instead of actively exercising independence from it is
framing bias — a named failure mode detailed elsewhere (encoding-failure-modes); order control is
the general claim that presented order can and should be overridden, and framing bias is what
happens when it is not.

## The Swiss cheese model

Because inquiry-based learning revisits and asks questions of the material across several
rounds, it is extremely difficult to miss information — each round is a layer, and the
probability that a gap survives every layer is low. By contrast, single-pass linear learning
misses information much more easily, since the brain does not act as a photocopier and will
overlook many points on a single pass (reference:
https://www.sciencedirect.com/science/article/pii/S0925753520300576).

## Snowballing

Snowballing is a scheduling application of order control: rather than covering a topic once at
full depth, the first pass is deliberately broad and superficial, and each subsequent pass adds
more depth. This is the same global-before-local principle stated at the level of a whole study
period rather than a single sitting — early passes establish relevance and structure; later
passes fill in detail once that structure exists. The operational schedule (where snowballing
sits inside a weekly study plan) is at ../03-details/techniques/prestudy-procedure.md.

## Relation to layers-of-learning

Order control and layers-of-learning are explicitly distinguished: **order control tells the
learner which order to consume information in; layers of learning tells them how to structure it
once reordered.** Order control is the decoupling claim and the permission to rearrange; layers
of learning is the concrete four-tier target structure (logic, concepts, important details,
arbitrary details) that the rearranged order is aimed at. Order control operationalised through
chunking is described as "self-regulated scaffolding": teaching oneself by deconstructing a
topic and reconstructing it in a form that is more manageable to understand and build expertise
in.

Information is typically presented in mixed layers — details and concepts interspersed, with
only infrequent hints toward logic, and logic itself often unlabelled in headings (figure:
../research/_assets/inline-images/How knowledge is presented.jpeg). Learning in the same mixed
order, without order control, produces cognitive overload because the brain cannot make the
information relevant as it arrives. The contents of each layer are not handed to the learner
explicitly; they must be constructed by the learner using chunking, moving between resources
(this movement between resources *is* order control; the desired outcome of that movement is the
layered structure — figure:
../research/_assets/inline-images/How knowledge is split into layers using cognitive effort.jpeg).
Sometimes the apparent "logic" already present in a resource is not the best chunk structure once
evaluated independently through importance-based chunking.

True expertise is organised, multi-directional, non-linear, and grouped (figure:
../research/_assets/inline-images/How knowledge and exerptise is structured.jpeg) — this is the
structure order control is used to build. Conventional (order-uncontrolled) learning produces
fluctuating relevance and high difficulty throughout, because detail arrives before the structure
that would make it relevant (figure: ../research/_assets/inline-images/How people normally learn.jpeg).
Learning in layers under order control instead front-loads effort on establishing logic, then
works through increasing detail while relevance stays high and difficulty stays in a manageable,
fluctuating range (figure: ../research/_assets/inline-images/How people should learn in layers.jpeg).

Prestudy is described as the predecessor mechanism to layering: it splits cognitive load across
multiple sessions to build the big picture and relevance before detail is added (see
../02-concepts/prestudy.md).
