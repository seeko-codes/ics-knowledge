## Canonical mechanism

Prestudy is study done before a main learning event (a class, lecture, or intensive dedicated
study session). Its purpose is to prime the brain for deeper learning by building a big-picture
scaffold in advance, so that new information arriving during the main event has a place to be
organised and connected, instead of arriving into a structureless space.

The brain struggles to know *what* to retain if it does not know *why* something is relevant.
Without prestudy, incoming information has no organisational structure to attach to; this
produces cognitive overload, which in turn makes information easier to forget and knowledge
slower to build. When intensive learning events (classes, lectures) recur daily or weekly, this
unrecovered overload compounds, forcing shortcuts or compromised performance, and the learner
feels progressively more overwhelmed with each session. Prestudy instead spreads the same
overall cognitive load and confusion across multiple, smaller sessions: a big-picture
understanding of relevance is built first, and detail is added later, once that foundation
exists. Over time this produces less confusion and faster, easier knowledge-building than
confronting the full density of a topic for the first time inside the main event itself
(figure: ../research/_assets/inline-images/Learning without prestudying.jpeg;
figure: ../research/_assets/inline-images/Learning with prestudying.jpeg).

The mechanism is also described as giving new information "a place to fit" — analogous to
having the edge pieces of a jigsaw puzzle already assembled before working on the interior
(figure: ../research/_assets/inline-images/Prestudying vs not_1.png). With prestudy, potential
connections have already been scoped and hypothesised, so the brain can spend its limited
resources during the main event connecting new information to an existing network and evaluating
whether it makes sense, rather than building that network from nothing while also trying to keep
pace with a live speaker (figure:
../research/_assets/inline-images/Overwhelm vs focused with prestudy.jpeg). In effect, correct
prestudy allows a learner to think faster than a live event can teach, which translates into
deeper, more interconnected questions and more value extracted from the session.

## Prestudy is more valuable than review ("bucket leaks")

Effective prestudy reduces how much is forgotten going forward, whereas reviewing already-learned
material only recovers what has already leaked away. Where time is constrained, prestudy is
prioritised over review: **if the bucket leaks, it is more important to plug the holes than to
keep filling it.** Choosing prestudy over review puts a smaller burden on future review, since
less will need to be re-caught later; choosing review over prestudy trades a larger, compounding
overload during the next unprepared main event for a smaller one now.

## Exact parameters

- **Scope**: with moderately efficient technique, prestudying 4-6 weeks of content in a single
  weekend is achievable, allowing a learner to move entirely beyond class pace.
- **Floor**: if no dedicated time is available, even a 10-minute skim before class is beneficial,
  provided the same framing principles are still followed (avoid detail, identify main ideas,
  identify key relationships, gain a big-picture understanding).
- **Brief vs. comprehensive prestudy and its downstream effect on Aim**: a brief prestudy of
  5-10 minutes does not leave room for a full Aim pass; it supports only a superficial Aim,
  developing the largest chunks and major relationships only. A more comprehensive prestudy
  supports a full Aim pass and can add further detail; if the Shoot step (the stage after Aim)
  has also been learned, that can be folded into a sufficiently comprehensive prestudy as well.
- **Timing**: prestudy can happen at any point before the main event; common patterns are
  prestudying the coming week's material over the prior weekend, or prestudying the day's
  material the same morning.

## Prestudy vs. TLS/Aim: WHEN vs. HOW

Both prestudy and the early stages of inquiry-based learning (IBL) aim to (1) find basic
relationships through active exploration, (2) create simple networks and schemas, and (3) build
big-picture understanding quickly — which is the source of common confusion between the two. The
distinguishing claim is:

- **Prestudy is about *when* learning happens.** It is a chronological step — an act of studying
  done before an intensive main learning event, particularly one prone to overwhelm (a fast
  lecture, for instance). Prestudying with the wrong method can waste time.
- **IBL methods (TLS, then Aim) are about *how* learning happens.** They are cognitive steps of
  the learning process, intended to develop deep knowledge and memory more efficiently. This
  process should ideally *begin* during prestudy but continues through subsequent study sessions
  until the topic is adequately encoded — it is not confined to the prestudy window
  (figure: ../research/_assets/inline-images/Prestudy vs IBL.jpeg).

Ideally IBL methods run during prestudy to form the topic's basic understanding. When prestudy is
not possible, IBL must instead run during the main event itself (very challenging, since the
learner is forced to keep pace with someone else) or after the main event (basic schemas are
formed live, then consolidated and properly primed/encoded with IBL afterward — more viable than
running IBL live, but still less optimal than a dedicated prestudy step).

**Previously (poorly) learned material** should still be re-approached with IBL during review or
exam preparation, since the original pass may not have built an appropriate knowledge schema even
if the content was nominally covered. Two signs indicate this re-approach is working correctly:
the process is *difficult* (indicating a genuine absence of prior schema, which would otherwise
show up as errors or inability to apply the knowledge under testing), and *knowledge gaps are
found regularly* (indicating real retention gaps caused by the missing schema).

### Academic grounding (from prestudy-tls-aim)

Inquiry-based learning has been debated within cognitivist frameworks over its theoretical
foundations and empirical support. It originates in constructivist views (Dewey, Bruner) holding
that learners build knowledge best by actively exploring and constructing it rather than
passively receiving it. The cognitivist critique, particularly from cognitive load theory, is
that IBL's characteristic lack of structured guidance can produce cognitive overload for novice
learners who lack the foundational knowledge needed to benefit from open-ended exploration, and
that this can hinder schema development (the cognitive process by which learners organise and
store knowledge in mental structures). The position taken is that IBL's underlying principles are
well-supported when properly structured: schema theory supports IBL's ability to foster deep,
conceptual understanding provided cognitive load is managed, and the live contention is largely
about what counts as "guidance" or "inquiry," not about the underlying mechanism. Cited further
reading: Ruiz-Martín & Bybee (2022); Sepp, Howard, Tindall-Ford, Agostinho & Paas (2019); Sweller,
Van Merrienboer & Paas (2019); Tanchuk (2020); Wirzberger, Herms, Esmaeili Bijarsari, Eibl & Rey
(2018).

## No-curriculum generalisation

The relevance- and scope-building principles that prestudy applies to structured curricula
generalise explicitly to self-directed learning from unstructured resources (books, courses,
on-the-job learning without a syllabus). The stated principle ordering is "always start with
relevance, then scope for relevance," using order control and keyword collection to do so
(source: ics-course/04-supplementary/01-live-clinics/41-lc35.md — "Live Clinic 35: Learning can
still happen without structure"). This session's substantive mechanism — how to recognise
relevant information, how the course's techniques build relevance in unstructured material, and
how to combat brain fog while reading unstructured resources — is **[video-only: not captured]**
(ics-course/04-supplementary/01-live-clinics/41-lc35.md); only the topic list and framing survive
in text.
