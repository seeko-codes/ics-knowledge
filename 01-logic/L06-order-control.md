## Statement

The order in which information is processed is a free variable, decoupled from the order in
which it is presented. Optimal encoding chooses its own order: global before local — backbone
first, then concepts, then details — with early structure held as a revisable hypothesis.
Presented order (textbook, lecture, curriculum) is optimised for exposition, not encoding, and
deferring to it is a named failure source (framing bias).

## Core claims

- Order control: the learner (or system) rearranges the order in which the brain consumes and
  organises information; layers of learning specify what the rearranged order should be
  ("order control allows us to rearrange; layers tell us how").
- Most resources put detail far too early; starting from deep foundational structure
  dramatically increases overall speed because structure gives later details relevance
  (converts arbitrary → important; see L03).
- Global-first passes recur at every scale: prestudy before a class; logic layer before
  concepts within a topic; multipass/Swiss-cheese layered passes when cramming; snowballing
  broad-then-deep across a study period.
- Early structure is hypothesis, not commitment: chunk structures and backbones remain
  revisable through the logic and concept layers; revisability declines (but never to zero)
  once detail layers are reached.
- Independence from presented order must be actively exercised: defaulting to the source's
  grouping is framing bias, which compounds across sessions if uncorrected.

## Independence

Without L06, there is no claim that order can and should be chosen: L03 supplies the ordering
criterion (importance) and L05 the reason staging helps (load), but neither states the
decoupling of processing order from presentation order — the claim on which prestudy, layers,
multipass, and framing-bias diagnosis all rest.
